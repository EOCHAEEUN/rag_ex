Dense의 강점

3. BM25 RETRIEVAL
09

BM25 구성 코드 · tokenization과 검색

CELL 6 · BM25 BUILD (2/2)
def tokenize(text):
    return re.findall(r"\w+", text.lower())


# 모든 chunk를 토큰 리스트로 바꾼다. (BM25는 토큰 리스트를 입력으로 받는다)
tokenized_corpus = []

for doc in corpus_docs:
    tokens = tokenize(doc.page_content)
    tokenized_corpus.append(tokens)


# 토큰화된 corpus로 BM25 검색기를 생성한다.
bm25 = BM25Okapi(tokenized_corpus)

print("BM25 문서 수:", len(corpus_docs))
CELL 7 · BM25 SEARCH
def bm25_search(query, k=5):
    # 질문도 corpus와 같은 방식으로 토큰화한다.
    query_tokens = tokenize(query)

    # 질문 토큰과 가장 잘 맞는 BM25 점수 상위 k개 문서를 반환한다.
    return bm25.get_top_n(
        query_tokens,
        corpus_docs,
        n=k,
    )

주의할 점

tokenize()는 현재 \w+ 기반의 단순 토큰화다. 그래서 BM25 성능은 tokenizer 품질의 영향을 받는다.

def print_results(title, docs):

5. HYBRID RETRIEVAL
11

Hybrid Retrieval · 둘을 함께 쓰되, 점수는 직접 합치지 않는다

Hybrid Retrieval

Dense Retrieval
+
BM25 Retrieval
→
Hybrid Retrieval

Dense와 BM25는 서로 다른 장점이 있으므로, 둘을 함께 사용하면 검색 후보를 더 다양하게 확보할 수 있다.

왜 점수를 직접 더하면 안 될까?

Dense distance : 0.18, 0.25, 0.31 ...
BM25 score : 12.4, 8.7, 5.1 ...

점수 체계가 다르기 때문에 그대로 더하거나 평균내는 방식은 적절하지 않다.

그래서 등장하는 방법
RRF · Reciprocal Rank Fusion
6. RRF
12

RRF · 점수가 아니라 “순위”를 합친다

RRF 공식

RRF(d) : 문서 d의 최종 RRF 점수
r : 각각의 검색기(Retriever)
k : 순위 영향력을 조절하는 상수, 보통 60
rankr(d) : 검색기 r에서 문서 d의 순위

Dense Ranking

순위문서
1위D3
2위D7
3위D1

BM25 Ranking

순위문서
1위D1
2위D4
3위D3
핵심: RRF는 원래 점수(score)가 아니라 순위(rank)를 결합한다. 그래서 점수 스케일 차이를 피할 수 있다.
6. RRF
13

RRF 계산 예시 · 1 / (k + rank)

≈ 0.01639 + 0.01587
≈ 0.03226

D7 예시

Dense 2위에만 등장

1 / (60 + 2)
≈ 0.01613

≈ 0.01613
두 검색기에서 함께 상위권이면
RRF 점수가 누적되어 더 위로 올라온다.
6. RRF
14

RRF 구현 코드 · 실제로는 이 정도다

CELL 12 · RRF
def rrf(dense_docs, bm25_docs, k=60):
    # chunk_id별 RRF 점수를 저장한다.
    scores = {}

    # chunk_id로 원래 Document를 다시 찾기 위한 저장소
    documents = {}

    # Dense 결과와 BM25 결과를 차례로 확인한다.
    for result in [dense_docs, bm25_docs]:

        # rank는 1위부터 시작한다.
        for rank, doc in enumerate(result, start=1):
            chunk_id = doc.metadata["chunk_id"]

            # 처음 등장한 chunk라면 점수를 0으로 초기화하고 Document를 저장한다.
            if chunk_id not in scores:
                scores[chunk_id] = 0
                documents[chunk_id] = doc

            # RRF 공식: 검색기별로 1 / (k + rank)를 더한다.
            # 두 검색기에서 모두 상위권이면 점수가 커진다.
            scores[chunk_id] += 1 / (k + rank)

    # RRF 점수가 높은 chunk_id 순서로 정렬한다.
    ranked_ids = sorted(
        scores,
        key=scores.get,
        reverse=True,
    )

    # 정렬된 순서대로 Document 목록을 반환한다.
    return [
        documents[chunk_id]
        for chunk_id in ranked_ids
    ]

사람 말로 번역하면

  1. Dense 결과와 BM25 결과를 모두 돈다.
  2. 각 문서의 rank를 확인한다.
  3. 1 / (k + rank)를 chunk별로 누적한다.
  4. 누적 점수가 높은 chunk부터 다시 정렬한다.
중요: RRF는 문서 내용을 다시 읽고 판단하는 모델이 아니다. 검색 결과의 순위만 결합한다.

query = "AI 기본법 시행령과 글로벌 규제 정합성은 어떻게 설명되나요?"

8. SUMMARY
16

핵심 정리와 다음 단계

Dense

Semantic Search
의미가 비슷한 문서를 찾는다.

BM25

Lexical Search
정확한 단어가 포함된 문서를 찾는다.

Hybrid

Dense + BM25
서로 다른 장점을 함께 사용한다.

RRF

Rank Fusion
서로 다른 검색 결과의 순위를 결합한다.

주의할 점

  1. Hybrid가 항상 Dense보다 좋은 것은 아니다.
  2. BM25는 tokenizer 품질의 영향을 받는다.
  3. RRF는 재판단 모델이 아니라 순위 결합 방식이다.

CELL 7 · BM25 SEARCH
def bm25_search(query, k=5):
    # 질문도 corpus와 같은 방식으로 토큰화한다.
    query_tokens = tokenize(query)

    # 질문 토큰과 가장 잘 맞는 BM25 점수 상위 k개 문서를 반환한다.
    return bm25.get_top_n(
        query_tokens,
        corpus_docs,
        n=k,
    )

CELL 12 · RRF
def rrf(dense_docs, bm25_docs, k=60):
    # chunk_id별 RRF 점수를 저장한다.
    scores = {}

    # chunk_id로 원래 Document를 다시 찾기 위한 저장소
    documents = {}

    # Dense 결과와 BM25 결과를 차례로 확인한다.
    for result in [dense_docs, bm25_docs]:

        # rank는 1위부터 시작한다.
        for rank, doc in enumerate(result, start=1):
            chunk_id = doc.metadata["chunk_id"]

            # 처음 등장한 chunk라면 점수를 0으로 초기화하고 Document를 저장한다.
            if chunk_id not in scores:
                scores[chunk_id] = 0
                documents[chunk_id] = doc

            # RRF 공식: 검색기별로 1 / (k + rank)를 더한다.
            # 두 검색기에서 모두 상위권이면 점수가 커진다.
            scores[chunk_id] += 1 / (k + rank)

    # RRF 점수가 높은 chunk_id 순서로 정렬한다.
    ranked_ids = sorted(
        scores,
        key=scores.get,
        reverse=True,
    )

    # 정렬된 순서대로 Document 목록을 반환한다.
    return [
        documents[chunk_id]
        for chunk_id in ranked_ids
    ]
